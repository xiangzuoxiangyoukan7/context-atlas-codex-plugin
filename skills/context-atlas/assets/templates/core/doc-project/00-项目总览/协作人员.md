# 协作人员

本文件维护项目确认过的稳定人员编号。Git 信息只用于发现和匹配候选身份；首次映射必须由用户确认，Git 提交不等价于业务内容批准。

| 人员编号 | 显示名称 | 所属团队 | 状态 | Git 用户名别名 | Git 邮箱摘要 |
| --- | --- | --- | --- | --- | --- |

## 填写规则

- 人员编号使用不复用的 `PERSON-*`；离开项目后改为 `inactive`。
- 多个 Git 用户名或邮箱摘要使用分号分隔。
- 邮箱默认只保存规范化邮箱的 SHA-256 摘要，不填写完整邮箱。
- 未确认候选使用 `PERSON-UNKNOWN` 出现在提案中，不直接写入本表。
- 提案区分内容提出者、文件操作方、内容确认者和 Git 提交者，不能用一个“作者”字段替代。
